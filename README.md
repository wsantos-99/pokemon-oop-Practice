# Pokémon Battle Simulator

An Object-Oriented Programming practice project featuring a turn-based Pokémon battle system.

## 📚 About This Project

This project was developed as a practical exercise to reinforce Object-Oriented Programming concepts in Python. It simulates a Pokémon-style battle system with:

- Turn-based combat
- Pokémon capture mechanics
- Type effectiveness
- Evolution system
- Trainer progression
- Item management

## 🎯 Learning Objectives

- Practice OOP principles (inheritance, encapsulation, polymorphism)
- Implement class hierarchies
- Work with data structures
- Build a complete game loop
- Practice Python programming

## 🛠️ Technologies

- Python 3.x
- OOP Design Patterns

## 📁 Project Structure


pokemon_battle_simulator/
├── data/ # Game data (Pokémon, moves, items)
├── models/ # Core classes (Pokémon, Trainer)
├── systems/ # Game systems (battle, capture)
└── main.py # Game entry point
